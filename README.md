# 🎬 MOVIE RECOMMENDER

MOVIE RECOMMENDER is a Movie Recommendation Web App built using Machine Learning and Streamlit.

The system recommends similar movies based on movie genres, cast, keywords, crew, and overview using Content-Based Filtering and Cosine Similarity.

# 🚀 Live Demo

https://movie-recommender-t5nmkgrg5mh9dqulvweydp.streamlit.app/

---

# ✨ Features

* Smart movie recommendations
* Modern Streamlit UI
* Content-Based Filtering
* Fast recommendation system
* Trending & Most Viewed sections
* Movie descriptions

---

# 🧠 Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Streamlit
* CountVectorizer
* Cosine Similarity

---

# 📂 Dataset

TMDB 5000 Movie Dataset

Files used:

* tmdb_5000_movies.csv
* tmdb_5000_credits.csv

---

# ⚙️ How It Works

1. Movie data is processed
2. Important features are combined
3. Text is converted into vectors
4. Cosine similarity is calculated
5. Similar movies are recommended
